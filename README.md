# Konsoul Downloads

A download helper for Windows. Every download from your browser asks "Where should this go?",
with your usual folder already picked. Press Enter, drag the file onto any folder, or paste a
folder link.

## Download

**[Get the latest version](https://github.com/Rwnohit/konsoul-downloads-releases/releases/latest)**
and download the file that ends in `_windows_x64.zip`.

## Install

1. Unzip it where you keep apps, for example in Documents (not in Program Files, so it can update itself).
2. Open `KonsoulDownloads.exe`. If Windows says "Windows protected your PC", click "More info", then "Run anyway".
3. Add the browser button (Chrome, Edge or Brave): open `chrome://extensions`, turn on "Developer mode",
   click "Load unpacked" and pick the `chrome-extension` folder inside the app folder.
4. In the app open Settings, then Browser Integration, and copy the API Key. Click the Konsoul Downloads
   button in the browser, paste it in "Pairing token" and press Save. It should say "Connected".

The same steps are in `START HERE.txt` inside the zip.

## Updates

The app looks for new versions on this page by itself and asks before it updates.
You can also use "Check for update" in the app menu.
